# sharukhanov.com

Личный сайт-портфолио / онлайн-резюме **Sharukhanov — AI Product & Project Leader**.

🔗 **Живой сайт:** [sharukhanov.com](https://sharukhanov.com)

## О проекте

Одностраничный сайт-резюме без фреймворков и сборки — весь сайт это один
файл `index.html` (HTML + CSS + ванильный JavaScript), размещённый на
GitHub Pages.

## Возможности

- 🌐 **Два языка** — английский и китайский, переключаются на лету
- 💼 **Проекты** — раскрывающиеся карточки с описанием реализованных кейсов
- 🗺️ **Карта путешествий** — интерактивная карта посещённых стран
- 🎵 **Vibe-плеер** — фоновая музыка по кнопке
- ❤️ **Счётчик лайков** — общий для всех посетителей (синхронизация между устройствами)
- 📸 **Фотоальбомы** — China, USA, Malta
- 📱 **Адаптивность** — корректно отображается на телефоне, планшете и десктопе

## Структура

| Файл | Назначение |
|------|-----------|
| `index.html` | Весь сайт: разметка, стили и логика |
| `cv_screenshot.jpg` | Скриншот проекта AI Forecasting Platform |
| `cv2_screenshot.png` | Скриншот проекта Computer Vision Inspection Platform |
| `vibe.mp3` | Музыка для кнопки Vibe |
| `CNAME` | Кастомный домен для GitHub Pages |

## Технологии

- HTML5 / CSS3 / Vanilla JavaScript
- [Abacus](https://abacus.jasoncameron.dev/) — общий счётчик лайков
- GitHub Pages — хостинг

## Локальный запуск

Так как это статический сайт, достаточно открыть `index.html` в браузере.
Для проверки в условиях, близких к продакшену (чтобы работали внешние
запросы), можно поднять простой локальный сервер:

```bash
python3 -m http.server 8080
# затем откройте http://localhost:8080
```
